# Sarati

**Sarati** ([sarati.net](https://sarati.net)) — Burkina Faso–first receivables and recurring payments for any business: hosted checkout (API) or merchant portal + SMS, Orange Money today, multi-country / multi-currency ready later.

*Sarati* is Dioula/Jula for agreement / contract / terms — chosen for trust and subscription/billing fit. Local planning folder slug remains `bf-recurring-payments`.

## Product promise

Any business in Burkina Faso can enroll a client by phone, send a bill, and get paid on the agreed day — without building a billing stack.
